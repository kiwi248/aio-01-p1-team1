7. 기능이 완성되기 전에는 커밋하지 않는다.
8. 팀원이 담당하는 파일은 명시적인 승인 없이 구조를 통합하거나 수정하지 않는다.

생활권 분석의 검색 대상은 임의의 Kakao 키워드가 아니라 청약정보에 등록된 공고다.


백엔드 생활권 API 흐름:

```text
주소 검색
  → 주소 결과가 있으면 좌표 반환
  → 없으면 Kakao 키워드 장소 검색
  → 둘 다 없으면 404
```

주변 시설은 Kakao 카테고리를 사용한다.

```text
SW8: 지하철역
MT1: 마트
HP8: 병원
```

예상 도보시간은 실제 보행 경로 API가 아니라 직선거리에 보정값을 적용한 추정치다.

## 10. 오늘 학습한 핵심

### Git

- `git rm --cached`는 로컬 파일을 남기고 Git 추적만 제거한다.
- `git commit --amend`는 마지막 커밋을 다시 만들기 때문에 해시가 변경된다.
- 수정된 원격 커밋은 일반 `--force`보다 `--force-with-lease`로 안전하게 갱신한다.
- 이미 공유 브랜치에 병합된 과거 기록은 함부로 재작성하지 않는다.
- PR 충돌은 파일 내용뿐 아니라 서로 달라진 커밋 계보 때문에도 발생할 수 있다.
- stash는 미완성 작업을 보존한 채 브랜치 병합을 진행할 때 유용하다.

### Streamlit

- `st.dialog`로 선택 공고의 상세정보 팝업을 만들 수 있다.
- 버튼 클릭 조건 안에서 팝업 함수를 호출한다.
- 들여쓰기가 잘못되면 문법 오류가 없어도 지도 전체가 버튼 조건 안에 들어가는 논리 오류가 생길 수 있다.

### PyDeck

- `ScatterplotLayer`는 단순 원형 좌표 표시에 적합하다.
- `IconLayer`는 시설 종류별 아이콘 표시에 적합하다.
- PyDeck `TextLayer`는 이모지 렌더링이 불안정할 수 있다.
- SVG data URL을 `icon_data`로 전달하면 외부 이미지 파일 없이 아이콘을 표시할 수 있다.
- 지도 정보는 `LineLayer`, `IconLayer`, `TextLayer`처럼 역할별 레이어로 나누면 이해와 유지보수가 쉽다.
